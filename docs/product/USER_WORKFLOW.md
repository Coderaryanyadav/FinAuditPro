# FinAuditPro — User Workflows & Target Personas

## 1. User Personas
- **Engagement Partner (FCA):** High-level assurance tracking, materiality sign-off, CARO conclusion review, and cryptographic audit report issuance.
- **Audit Manager (ACA):** Procedure assignment, review note clearance, trial balance adjustment approvals, and lead schedule review.
- **Article Assistant / Senior:** Data import, voucher testing, sampling execution, evidence attachment, and working paper drafting.
