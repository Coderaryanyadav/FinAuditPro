# FinAuditPro — Desktop Navigation & Interaction

## 1. Navigation Architecture
Guided 4-stage workflow sidebar:
1. **Engagement Dashboard:** KPIs, completion gates, timeline.
2. **Financial Data:** Trial balance, adjustments, lead schedules, analytics.
3. **Audit Fieldwork:** Risk matrix, sampling, working papers.
4. **Statutory Compliance:** CARO 2020, Form 3CD checkers.
5. **Review & Finalisation:** Review notes, misstatements, report generation.
6. **AI Assistant:** Persistent slide-over drawer (`Ctrl+Shift+A`).

## 2. Keyboard Shortcuts
- `Ctrl + K` / `Cmd + K`: Global Command Palette.
- `Ctrl + F` / `Cmd + F`: Table search/filter.
- `Ctrl + Shift + A`: Toggle AI Copilot.
- `Ctrl + S`: Save working paper.
