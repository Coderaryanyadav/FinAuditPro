# FinAuditPro Installer & Packaging Configurations

This directory contains standalone installer definitions, build configurations, and packaging assets:
- **`finauditpro.spec`**: PyInstaller bundle packaging specification located at repository root.
- **macOS Apple Silicon / Intel**: Drag-and-drop `.dmg` distribution packaging definitions.
- **Windows x64**: Inno Setup / WiX MSI installer configurations.
- **Linux**: AppImage and Debian package specifications.
