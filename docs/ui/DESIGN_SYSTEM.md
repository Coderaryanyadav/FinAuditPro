# FinAuditPro — UI Design System & Tokens

## 1. Color Palette Tokens
- **Background Deep:** `#0B0F19` (App shell base)
- **Surface Elevation 1:** `#111827` (Card & table containers)
- **Surface Elevation 2:** `#1F2937` (Hover states & headers)
- **Accent Primary (Emerald):** `#10B981` (Balanced / Approved / Success)
- **Accent Warning (Amber):** `#F59E0B` (Review Required / Attention)
- **Accent Danger (Rose):** `#EF4444` (Out of Balance / Rejected / High Risk)
- **Accent Informational (Indigo):** `#6366F1` (AI Copilot / Active Selection)
- **Text Primary:** `#F9FAFB`
- **Text Secondary:** `#9CA3AF`

## 2. Typography
- **UI Text:** Inter / Segoe UI / SF Pro Display, sans-serif.
- **Numbers & Data Tables:** Tabular monospace (`JetBrains Mono` / `Courier New`) for vertical decimal alignment.
